Important Instructions !!

To ensure the AI edits sync correctly, please follow these exact steps:

  1. PREREQUISITE: Ensure your original video file is ALREADY inside the Media Pool in DaVinci Resolve.
  2. IMPORT EDL: Go to File > Import > Timeline... and select the downloaded .edl file.
    ⚠️ IMPORTANT: In the settings window, manually set the Frame Rate to match your video (e.g. 30, 60 fps).
  3. TO VIEW YOUR PREVIOUS TIMELINE:
    1. Drag your previous timeline from the Media Pool into the current editor.
    2. Right-click the clip > Select Decompose in Place.
    3. Select "Using Clips Only".
    (Advanced: Only check "Preserve Audio Data" if you have complex Fairlight Bus routing).
